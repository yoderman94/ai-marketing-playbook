# HANDOFF: B2B Service Blog Pipeline Template

State of the template, what is verified, and the choices that look like bugs but are deliberate. Read this before you change the scripts or the stage files.

Version: 2.0.2 (2026-10-09). Lives in the AI Marketing Playbook repo at `claude-code/b2b-blog-pipeline/`.

---

## 1. What this is

A blog pipeline that markets **to** service business owners, in an agency's own voice, under its own byline. It's a template: you clone it once per vertical, fill in the placeholders, and run it there. Everything in it is vertical-agnostic on purpose.

When you clone it, reset `VERSION` to `1.0.0` and start a fresh `CHANGELOG.md`.

## 4. Deliberate choices

- **Stage 11 can't be scripted.** Magnific's sign-in doesn't carry into `claude -p`. Don't add it to the batch script.
- **Permissions default to an allowlist**, not `--dangerously-skip-permissions`. If a stage needs a new tool, add it to the default list in `scripts/blog-pipeline.sh` and to the docs, instead of switching the default to bypass.
- **The QC report heading** is `Stage 3 QC Report (auto-generated by qc.sh)`. All four QC files strip the old report by that exact text. Change it in all four or none.
- **Gemini is retired from Stage 0 (2026-10-14).** The runner has no research mode and no Gemini login gate. `scripts/gemini-*` are kept, marked retired, for manual use only.
- **No Google Drive upload.** Drafts stay local. It was removed on purpose: partial uploads couldn't be cleaned up.
- **The slug map** (`logs/blog-slug-map.log`) is written by `blog-pipeline.sh` and read by `collect-post.py` through the same path (`BLOG_LOG_DIR` or `--slug-map`). Keep them in step.
- **Fonts** are OFL only, so the repo can stay public. A commercial brand font goes in `.gitignore`.

## 5. Open items

- Stage 0's five-source flow depends on third-party APIs that change. Expect to adjust tool names in `instructions/00-deep-research.md` when a vendor renames an MCP tool.
- The QC has no image checks: a placeholder alt text passes.
- `reference/readability-targets.json` is supported but not shipped; the defaults (grade 9, Reading Ease 60) apply.

## 6. Test log

**2026-10-09, release test (macOS, Claude Code 2.1.295):**

- One topic seed (commercial HVAC maintenance contracts), fictional agency, `no-gemini`, short sleeps.
- Stages 0-10 all completed; 1 of 1 job; exit 0. About 27 minutes; Claude cost about $12.90 (Stage 2 alone $4.80).
- Stage 0: Exa 3 searches + 6 fetches, Tavily 4 searches + 1 extract; SearXNG returned nothing (engine CAPTCHAs on the test machine; fixed in 2.0.1 with a tested engine set); bundle 12.9 KB.
- Stage 5 renamed the slug; the slug map carried the Stage 0 research into `posts/2026-11-04-win-more-maintenance-contracts/`.
- QC: PASS. Stage 8: all 6 external sources load, all 16 claims match. Its only blocker was the fake `.example` domain.
- Allowlist mode: one refusal (a DataForSEO MCP the test machine had, outside the list); the stage noted it and went on.

**Found and fixed during the test:**

- `--setting-sources project,local` also drops user-level MCP servers, so Stage 0 ran on web search alone and still "passed". The pipeline now warns before a run when Exa or Tavily isn't connected.
- URL paths used `[YOUR_VERTICAL]`, which breaks when the vertical has a space. They now use `[YOUR_VERTICAL_SLUG]`.
- Stage 4's H3 is an 80-150 character image-SEO title, too long for a cover. Covers now try the H1 SEO title first.

**Not tested:** a live Gemini Deep Research pass (the superpowers-chrome MCP was down on the test machine; the login check's "can't tell" path was tested and writes no email), and Stage 11 (needs Magnific credits).
